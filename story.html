How to Navigate

1. Navigation

↑ ↓

Use the Arrow Keys to switch between:

  • Found Clues
  • Answer Section

2. Select Clue

Space → Enter the Clue Grid

Use ← → to move between clue cards.

Space again to add the clue to answer queue.

3. Go Back

ESC → Return to main selection

4. Enter Answer Section

Use ↓ to highlight the Answer area.

Space → Enter the Answer Section.

5. Manage Answer

Use ← → to move between pins.

Space → Delete selected pin

Enter → Submit your solution
